# Agent OS — 72-Hour Onboarding Line

## Hour 0: Client says yes
- Send payment link (Razorpay for setup fee) + config sheet
- Book the 30-min access call

## Hour 1-24: Setup
- Access call: Instagram, Google Business, booking link
- Bot message bank filled from config sheet
- WhatsApp quick replies / API flow configured and tested with 5 test messages

## Hour 24-48: Landing page
- Fill template config block (agent-os/landing-template.html)
- Push to a new GitHub Pages site: {agent-name}.pages style, live same day
- Google Business updated with new link

## Hour 48-72: Content
- First content batch produced from their clips/photos
- Week 1 scheduled
- Money report baseline started (today's numbers = the "before" picture)

## Day 7: First check-in
- Show the client the first report + bot conversation stats. This is the moment they stop doubting.

## Failure protection
- Client doesn't send clips within 5 days? Auto-nudge + phone call. Their only job is 15 minutes a week.
