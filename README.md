# Lead Engine — Private Growth Studio for Real Estate Agents

Static site. No backend, no Base44 dependency. Works on any host.

## Deploy on Vercel (2 minutes)
1. Go to vercel.com → Add New Project → Import this GitHub repo
2. Framework Preset: **Other** · Root Directory: **docs**
3. Deploy. Done.

## Deploy on GitHub Pages (already live)
Repo Settings → Pages → Branch: main, folder: /docs

## Deploy on Netlify / Cloudflare Pages
Build command: none · Publish directory: **docs**

## One config to change
`docs/index.html` → search for `WA_NUMBER` near the bottom and put your
WhatsApp number in international format (digits only). The contact form
then delivers leads straight to your WhatsApp — no backend, no cost.
